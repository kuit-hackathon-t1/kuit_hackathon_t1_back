# KUIT Hackathon T1 Backend

청춘의 시간을 작은 여행 미션으로 남기는 해커톤 백엔드 프로젝트입니다.

사용자는 여행 스타일을 선택하고, 추천받은 미션을 채집해 보관할 수 있습니다.  
여행을 진행하며 쌓은 채집 표본과 그에 담긴 추억들이 채집함에 쌓입니다.

## Tech Stack

- Java 17
- Spring Boot
- Spring Web MVC
- Spring Data JPA
- Gradle
- Lombok
- H2 / MySQL
- Spotless (Google Java Format)
- EditorConfig

## Getting Started

```
./gradlew bootRun
```
